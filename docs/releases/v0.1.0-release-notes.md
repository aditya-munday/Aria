# Aria v0.1.0 Release Notes

**Release Date:** 2026-09-02  
**Tag:** `v0.1.0`  
**License:** Apache-2.0  

Aria v0.1.0 is the foundational release of the living presence voice assistant featuring dual persona modes (**Aria Mode** and **Jarvis Mode**), canonical low-latency voice pipeline, transparent compositor overlay, screen awareness tools, and strict Directioner AI delegation boundaries.

---

## 🌟 Key Features

### 1. Canonical Voice Loop Pipeline
- **Wake Word Detection (`aria/core/wake/`):** openWakeWord engine with dual models ("Aria" for warm elegance, "Jarvis" for tactical HUD presence).
- **Voice Activity Detection (`aria/core/vad/`):** Silero VAD for end-of-utterance segmentation and silence trimming.
- **Streaming STT (`aria/core/stt/`):** smallest.ai low-latency streaming speech-to-text.
- **LPU Reasoning Engine (`aria/core/llm/`):** Groq `llama-3.3-70b-versatile` delivering ultra-low Time-To-First-Token (<200ms) with distinct system prompts and function calling.
- **Streaming TTS (`aria/core/tts/`):** smallest.ai streaming text-to-speech.
- **Real-Time Audio Analysis (`aria/core/audio/`):** Computes RMS amplitude, spectral energy, zero-crossing pitch proxy, and dynamic variance beat detection to drive visual presence.

### 2. Dual-Mode Visual Presence & Compositor Overlay
- **Aria Mode Soft Orb (`aria/visual/aria_mode/`):** Luminous cool blues (`#8FA8FF`) and soft violets (`#D4BFFF`) with gentle bloom, orbital micro-particles, and voice-reactive pulsing.
- **Jarvis Mode Arc-Reactor HUD (`aria/visual/jarvis_mode/`):** Multi-layer rotating concentric rings, high-intensity electric cyan (`#00E5FF`) core flare, and particle vortex fields.
- **Seamless Transformation (600–800ms):** Smooth interpolation between Aria and Jarvis modes.
- **Canvas Floating Panels (`aria/visual/canvas/`):** Adaptive layout engine (`CENTER`, `FAN`, `GRID`, `DOCKED`) with ephemeral TTL lifecycle and voice pinning.
- **Overlay WebSocket Server (`aria/visual/overlay/server.py`):** Real-time snapshot broadcast to transparent desktop compositor frontends.

### 3. Directioner AI Intent Safety Boundary & Option A Confirmation UX
- **Zero Local OS Execution:** All OS-level actions are turned into typed `IntentPayload` contracts and delegated across the Directioner AI API.
- **Option A Dual-Channel Confirmation:** Spoken action summary + high-contrast amber visual card with 10-second auto-abort countdown timer.
- **Strict Critical Safeguards:** Multi-word confirmation keyword matching for critical operations.
- **Intent Audit Logging:** Persistent recording of all delegated intent requests in SQLite database.

### 4. Advanced Vision Control & Screen Awareness
- Abstract `ScreenCaptureProvider` and `VisionAnalyzer` interfaces.
- Desktop screen/active window capture with graceful fallback for headless runners.
- Groq `inspect_screen` tool for answering visual queries.

### 5. Media Player & Beat Reactivity
- Built-in `MediaPlayerController` with playback tracking.
- `BeatVisualSynchronizer` boosting particle speeds and ring flare in synchronization with musical beats.

### 6. Unified CLI & Preferences Management
- `aria run`: Execute simulated or real voice pipeline turns.
- `aria benchmark`: Run automated latency and throughput test harness.
- `aria config`: Manage user settings persisted in SQLite.
- `aria memory`: Statistics and complete privacy purge (`clear_all_memory()`).
- `aria overlay`: Start visual overlay WebSocket server.
